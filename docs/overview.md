# Livingstone Supongo (LSTONE.COM) — обзор

DOS‑игра для IBM PC/CGA, Opera Soft, 1986: перевод на 8086 испанской «Livingstone Supongo» (ZX Spectrum).
Файл `LSTONE.COM`: SHA‑1 `9cadce0a57e5b8052889e007fa698c29bd75fea7`, 62 336 байт. Управление 1–4 + QAOP.

Код — почти дословная трансляция Z80: `AH`≈A, `BX`≈HL, `CX`≈BC, `DX`≈DE.

## Структура файла

Обычный COM: **адрес в сегменте игры = смещение в файле + 0x100**.

В распространённой копии стоит трейнер, ремастер (`remaster/src/gamefile.cpp`) и `tools/emu.py`
при загрузке его снимают:

| Адрес | Трейнер | Оригинал |
|---|---|---|
| `0x064d` | `jmp` — game over пропускается | `0x75` (`jne`) |
| `0x3f96` | `nop nop` — динамик молчит | `e6 61` (`out 61h, al`) |

Раньше разбор шёл по киевской русской версии `LIVINGST.COM` (ПО «Электронмаш», 1991,
SHA‑1 `eeab5137…`, 62 080 байт): тот же образ игры, но со 256‑байтной обёрткой «(C) S.Kovalenko»
(джойстик → клавиатура) впереди, поэтому там адрес = смещение − 0x100. `tools/extract_gfx.py`
по‑прежнему узнаёт её по первым байтам `e9 ac 00`; ремастер её больше не принимает.

## Карта памяти образа

| Адрес | Что |
|---|---|
| `0x0000` | старт: сегменты, `SP=0xFEEE`, `jmp 0x100` |
| `0x0100–0x3FB9` | код |
| `0x3fc0` | данные комнат — см. `graphics.md` |
| `0x59ac` / `0x69ac` | тайлсеты A / B |
| `0x702c` | блоки комнат |
| `0x7c89` | таблица комнат (63) |
| `0x7d07` | таблица клавиш (скан‑коды; бит 7 = нажата) |
| `0x7e..0x7f` | звуковые данные и переменные звука/таймера |
| `0x8d05` | скрипт раскладки HUD |
| `0x8ddd–0xdd98` | спрайты (196) |
| `0xdd99–0xe6xx` | переменные, таблица объектов `0xde46`, тайловые буферы `0xe04c`/`0xe36c` |
| `0xf000` | остаток дискового загрузчика (`INT 13h`) |
| `0xf110` | заплатка русификации HUD |

## Система

- **Клавиатура** — свой `INT 9` в `0x3d6f`; при нажатии/отпускании переключает бит 7 у записи в `0x7d07`.
  Опрос в `0x33cb` собирает биты направлений и огня в `0xdd99`.

  | Запись | Клавиша | Запись | Клавиша |
  |---|---|---|---|
  | `7d07–7d0a` | Q W E R (оружие) | `7d0b–7d0e` | ← → ↑ ↓ |
  | `7d0f` | Space | `7d10` | Scroll Lock |
  | `7d11` | Enter | `7d12/13` | E R |
  | `7d14` | S | `7d16–18` | Alt Ctrl Del → перезагрузка |

- **Чит**: одновременно ← → E R ↓ превращает `dec ah` в `0x644` (уменьшение жизней `0xdda2`) в `NOP NOP`;
  S возвращает как было. Жизней в начале 7.
- **Таймер** — `INT 1Ch` в `0x3d2d`, PIT перепрограммирован на делитель `0x2E9E` (~100 Гц).
  Счётчики `0xdd9b`, `0x7fb2`, `0x7fb3`; каждый второй тик вызывается звук `0x3e3d`.
- **Звук** — PC speaker (порт `0x61`), проигрыватель `0x3e3d`, мелодии начиная с `0x7ea6`.
- Установка векторов — `0x3cde`.

## Инструменты

- `tools/emu.py` — эмулятор на unicorn: CGA, IRQ клавиатуры/таймера, сценарии ввода, скриншоты, дампы RAM, покрытие.
- `tools/rd.py` — дизассемблер рекурсивным спуском, можно подать покрытие (`cov.json`) → `re/livingst.lst`.
- `tools/extract_gfx.py` — тайлы, комнаты, спрайты, HUD → `re/`.
- `tools/disasm.py` — дизассемблировать диапазон.

Зависимости: `pip install -r tools/requirements.txt` (make_app.sh сам создаёт `.venv`).
