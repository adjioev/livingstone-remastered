# Livingstone Supongo (LSTONE.COM) — графика

Адреса — смещения в сегменте игры (`адрес = смещение в файле + 0x100` для `LSTONE.COM`,
см. `docs/overview.md`). Всё извлекается скриптом `tools/extract_gfx.py` → `re/gfx`, `re/rooms`, `re/sprites`.

## Видеорежим

- `0x33a6` — `INT 10h AX=0004h`: CGA 320×200, 4 цвета. Видеопамять `B800:0000` (чётные строки)
  и `B800:2000` (нечётные), 80 байт на строку, 2 бита на пиксель, старшие биты — левый пиксель.
- Палитра выбирается через `INT 10h AH=0Bh BH=1`: `0x33af` — палитра 0 (зелёный/красный/жёлтый),
  `0x33bd` — палитра 1 (циан/маджента/белый). Текущая палитра хранится в `cs:0x35db`.
- `0x35ae` — выбор палитры по комнате: комнаты `0x2c..0x37` и `0x3a` (пещеры) → палитра 1, остальные → 0.
- Фон и яркость игра **не задаёт**. В режиме 4 BIOS выставляет регистр выбора цвета `0x3D9 = 0x30`
  (яркие цвета, чёрный фон) — экстрактор использует это допущение. **Не проверено на живом DOSBox.**

## Экран

```
строки 0..19  (0..159 px)   игровое поле: карта 40×20 тайлов 8×8
строки 20..24 (160..199 px) HUD
```

| Буфер | Адрес | Назначение |
|---|---|---|
| `TILEMAP` | `0xe04c` | текущая карта 40×20 (800 байт), индексы тайлов набора A |
| `TILEMAP_PREV` | `0xe36c` | копия предыдущего кадра; также off‑screen буфер для спрайтов |
| `ROOM` | `0xe04a` | номер текущей комнаты |
| `REDRAW` | `0xe04b` | флаг «экран изменился» |

Отрисовка «грязных» тайлов: `0x357e` сравнивает `TILEMAP` с `TILEMAP_PREV` и перерисовывает только
изменившиеся ячейки.

## Тайлы 8×8

Формат: 16 байт = 8 строк по 2 байта (8 пикселей CGA).

| Набор | Адрес | Кол‑во | Рисует | Содержимое |
|---|---|---|---|---|
| A | `0x59ac` | 256 | `0x349b` (AX=индекс), `0x34ed` (AH=индекс) | фон комнат |
| B | `0x69ac` | 104 | `0x34ad` (AX=индекс, CX=строка/столбец) | HUD, цифры, рамки |

Обе процедуры адресуют экран так: `DI = row*0x140 + col*2` (одна строка тайлов = 4 строки в каждом банке CGA).

## Комнаты (63 записи, 62 реальные + пустая `0x3e`)

```
0x7c89  ROOM_TABLE[63] : word — смещение от ROOM_DATA
0x3fc0  ROOM_DATA      : count, затем count × { col:byte, row:byte, block:word }
0x702c  BLOCKS         : по смещению block: { w:byte, h:byte, tiles[w*h] }  (0 = прозрачно)
```

Сборка комнаты — `0x3505`: очищает `TILEMAP`, накладывает блоки, затем переходит на `0x1c7d`
(дальнейшая обработка комнаты/объектов — не разобрана). Комната `0x3d` — заставка (навес, туземцы,
надпись «ЛИВИНГСТОН»). Все комнаты — `re/rooms/atlas.png`.

## Спрайты (196 штук)

```
0x8ddd .. 0xdd99  непрерывная цепочка записей { w:byte (в байтах, 4 px/байт), h:byte (строк), pixels[w*h] }
```

- Пиксели линейные, CGA 2bpp, цвет 0 — прозрачный (маска строится на лету в `0x3b4f`).
- Объект ссылается на кадр полем `+0x26` своего слота (таблица объектов `0xde46`, слоты по 0x28 байт).
  Поля `+0x1a/+0x1b` — позиция (x в байтах), `+0x1c/+0x1d` — смещение окна внутри кадра (клиппинг),
  `+0x1e/+0x1f` — видимые ширина/высота.
- Рисование: `0x3ae6` кладёт спрайт в off‑screen буфер `0xe36c` (шаг строки в `0xde3b`),
  `0x3a83` копирует прямоугольник буфера в видеопамять (`0xde39` — позиция, `0xde41` — размер).
  `0x3601` помечает тайлы под объектом как «грязные» (`0xff`) для перерисовки.

Основные группы (полный список с адресами — `re/gfx/sprites_pal0.png`):

| Адреса | Что |
|---|---|
| `8e69..969d` | Ливингстон вправо: ходьба, прыжок, присед, падение, смерть |
| `c831..cf4d` | Ливингстон влево |
| `9729..9a25`, `d607..d897` | траектории/шест для прыжка с шестом |
| `9afd..9b49` | всплывающие очки 100 / 250 / 500 |
| `9b6f..9c6f` | взрыв гранаты |
| `a131..a6b1`, `d007..d581` | туземцы, обезьяны и т.п. |
| `ae8d..af13` | два туземца с заставки (анимация) |
| `b7bb..b841`, `c437..c4bd` | крокодилы |
| `b8df`, `c54f` | Стэнли (финал) |
| `bb15` | плашка «ПО ЭЛЕКТРОНМАШ», `c003` — «г. КИЕВ» |

## HUD

- Скрипт раскладки: `0x8d05`, интерпретатор `0x0d2d`.
  Байт `0x00 row col` — установить позицию; `0xff` — конец; любой другой — индекс тайла набора B.
  Рендер — `re/gfx/hud.png`.
- Полоски силы/пищи/воды: `0x3253`, `0x3261`, `0x323f` (`0x326d` заливает байтами 0x55/0xaa/0xff прямо в
  видеопамять; значения в `0xddac`, `0xddad`, `0xddb5`).
- Индикатор выбранного оружия: `0x3324` (XOR‑рамка `0x336b` вокруг иконки, позиции в таблице `0x7fb6`;
  выбор оружия — `0xddb1`, клавиши Q/W/E/R → `0xddb9 = 1..4` в `0x3444`).

## Киевская версия LIVINGST.COM (только для справки)

В `LSTONE.COM` этого нет.

Игровые тайлы **не переведены**: в наборе B по‑прежнему испанские подписи «FUERZA / VIVERES / AGUA».
Перевод сделан заплаткой:

- `0x24af` рисует HUD, затем `call 0xf110`.
- `0xf110` копирует готовый битмап «СИЛА ПИЩА ВОДА» (5 строк × 31 байт по адресу `0xf15e`)
  **прямо в видеопамять** по адресу `B800:1A95` (3 строки в чётный банк, 2 в нечётный).
- Плашки «ПО ЭЛЕКТРОНМАШ» / «г. КИЕВ» и надпись «ЛИВИНГСТОН» в комнате `0x3d` — уже в данных игры.
- По адресу `0xf000` лежит остаток загрузчика с `INT 13h` (чтение секторов, затем `INT 20h`) —
  в этой версии не вызывается.

## Открытые вопросы

- Большой логотип «ЛИВИНГСТОН» цепочным шрифтом на заставке рисуется не из `TILEMAP` — процедура не найдена.
- `0x1c7d` (после сборки комнаты): вероятно, расстановка объектов/анимированных тайлов.
- Реальная палитра/фон — сверить со скриншотом из DOSBox.
